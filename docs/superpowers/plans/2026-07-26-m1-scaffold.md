# M1 — Scorer Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the FastAPI project skeleton, Pydantic request/response schemas for the future `/v1/score` contract, a SQLAlchemy model + Alembic migrations against Postgres for logging scoring runs, a dataset ingestion module for loading hallucination-benchmark examples, Docker Compose packaging, and a CI skeleton for the hallucination-factual-consistency-scorer project — no claim extraction or entailment-checking logic yet (that's M2).

**Architecture:** A single FastAPI service (`src/scorer/`) with a `/health` endpoint, Pydantic schemas for the future score-request/response contract, a SQLAlchemy `ScoringRun` model persisted to Postgres via Alembic-managed migrations, a dataset module that parses a normalized JSONL shape (`answer`, `sources`, `label`) so M3's benchmark harness can convert whichever public dataset it picks (RAGTruth/HaluEval/subset) into this same shape, packaged with Docker Compose (API + Postgres), and gated by a GitHub Actions CI workflow (lint + type-check + test).

**Tech Stack:** Python 3.11+, FastAPI, Pydantic v2, pydantic-settings, SQLAlchemy 2.0, Alembic, psycopg (Postgres driver), pytest + httpx, ruff, mypy, Docker Compose.

## Global Constraints

- Python version floor: 3.11 (per PLANNING.md §5 Tech Stack).
- Backend framework: FastAPI with Pydantic v2 schemas (per PLANNING.md §5 — "Backend: Python, FastAPI, Pydantic").
- Storage: Postgres in production/Docker Compose; SQLite in-memory permitted only for fast unit tests of SQLAlchemy models (per PLANNING.md §5 — "Storage: Postgres (scoring runs, benchmark results)").
- Packaging: Docker Compose must bring up API + Postgres together (per PLANNING.md §5 — "Packaging: Docker Compose (API + Postgres + report viewer)"; report viewer is out of scope for M1, it lands in M4 per PLANNING.md §8).
- No claim-extraction or entailment-checking logic in this milestone — M1 is scaffold only, per PLANNING.md §8 M1 definition ("FastAPI project, Pydantic schemas, Docker Compose, Postgres migrations, dataset ingestion script").
- Dataset ingestion in M1 targets a normalized internal JSONL shape only (`answer: str`, `sources: list[str]`, `label: "supported" | "hallucinated"`); wiring up a specific real-world dataset (RAGTruth/HaluEval) is M3's job per PLANNING.md §7, chosen "at build time" — M1 just needs the loader and the shape it produces.
- Secrets (e.g. `DATABASE_URL`) must be sourced from environment variables only, never hardcoded (per PLANNING.md §9 Best Practices Checklist).
- Source layout: `src/scorer/` package (src-layout), tests under `tests/`.

from pathlib import Path
from typing import Literal

from pydantic import BaseModel


class DatasetExample(BaseModel):
    answer: str
    sources: list[str]
    label: Literal["supported", "hallucinated"]


def load_examples(path: Path) -> list[DatasetExample]:
    examples: list[DatasetExample] = []
    with path.open() as f:
        for line in f:
            line = line.strip()
            if not line:
                continue
            examples.append(DatasetExample.model_validate_json(line))
    return examples
```

from logging.config import fileConfig

from alembic import context
from sqlalchemy import engine_from_config, pool

from scorer.config import settings
from scorer.db.base import Base
from scorer.db.models import ScoringRun  # noqa: F401 — ensures the table is registered on Base.metadata

config = context.config
config.set_main_option("sqlalchemy.url", settings.database_url)

if config.config_file_name is not None:
    fileConfig(config.config_file_name)

target_metadata = Base.metadata


def run_migrations_offline() -> None:
    url = config.get_main_option("sqlalchemy.url")
    context.configure(
        url=url,
        target_metadata=target_metadata,
        literal_binds=True,
        dialect_opts={"paramstyle": "named"},
    )
    with context.begin_transaction():
        context.run_migrations()


def run_migrations_online() -> None:
    connectable = engine_from_config(
        config.get_section(config.config_ini_section, {}),
        prefix="sqlalchemy.",
        poolclass=pool.NullPool,
    )
    with connectable.connect() as connection:
        context.configure(connection=connection, target_metadata=target_metadata)
        with context.begin_transaction():
            context.run_migrations()


if context.is_offline_mode():
    run_migrations_offline()
else:
    run_migrations_online()
```
